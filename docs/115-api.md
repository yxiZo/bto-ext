# 115 网盘离线下载 API

> 抓包时间: 2026-06-09 | 浏览器: Chrome 148 | 用户已扫码登录

## 离线下载完整链路

### Step 1 — 获取签名

```
GET https://115.com/?ct=clouddownload&ac=space
Cookie: <全量 Cookie>
```

**Response:**
```json
{
  "state": true,
  "data": 50002341938027,
  "sign": "010c2aa9fcc3c7cc2931b4ffa2419108",
  "time": 1780993092,
  "size": "45.48TB",
  "url": "",
  "bt_url": "",
  "limit": 53687091200
}
```

| 字段 | 说明 |
|------|------|
| `sign` | 签名，Step 2 必须携带 |
| `time` | Unix timestamp（秒），Step 2 必须携带 |
| `data` | 疑似 user_id 或 session id |

### Step 2 — 提交离线任务

```
POST https://clouddownload.115.com/web/?ac=add_task_urls
Content-Type: application/x-www-form-urlencoded
Cookie: <全量 Cookie>

sign=010c2aa9fcc3c7cc2931b4ffa2419108
&time=1780993092
&uid=342277133
&url[0]=magnet:?xt=urn:btih:D22BD1E3FD04786E45007C076AF984A1ED760F2E
&savepath=
&wp_path_id=3151967931743600014
```

| 参数 | 来源 | 说明 |
|------|------|------|
| `sign` | Step 1 响应 | 签名 |
| `time` | Step 1 响应 | Unix 秒时间戳 |
| `uid` | Cookie `UID` 字段取 `_` 前部分 | 用户 ID |
| `url[0]` | 磁力链接 | 支持数组 `url[0]` `url[1]` ... 批量提交 |
| `savepath` | 可为空 `""` | 保存路径（留空用默认） |
| `wp_path_id` | 可选 | 目标目录 ID |

**Response:**
```json
{
  "state": true,
  "errno": 0,
  "errcode": 0,
  "result": [
    {
      "state": true,
      "errno": 0,
      "errcode": 0,
      "info_hash": "d22bd1e3fd04786e45007c076af984a1ed760f2e",
      "url": "magnet:?xt=urn:btih:D22BD1E3FD04786E45007C076AF984A1ED760F2E"
    }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `state` | 提交成功 |
| `result[].info_hash` | BT info hash（小写 hex） |
| `result[].url` | 原始磁力链接 |

## 鉴权

**Cookie 全部字段**都需携带（通过 `browser.cookies.getAll` 获取后拼成 `k=v; k=v` 格式）：

```
GST, USERSESSIONID, UID, CID, SEID, KID, PHPSESSID, acw_tc, ...
```

其中 `UID` 格式为 `{uid}_{timestamp}`，提取 `_` 前部分得到 `uid` 参数。

## 其他发现

- 115 新版使用 Next.js (React Server Components)，`_rsc` 参数标记 RSC 请求
- 文件列表 API: `GET https://webapi.115.com/files?...&format=json`
- 离线下载路径选择: `GET/POST https://webapi.115.com/offine/downpath`
- 配额查询: `POST https://clouddownload.115.com/web/?ac=get_quota_package_info&uid=xxx`
